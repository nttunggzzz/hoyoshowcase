Dữ liệu & APIGiữ nguyên dữ liệu, hiểu đúng ý nghĩa.

Phân biệt snapshot đầy đủ, model cho giao diện và tùy chỉnh ảnh. Một con số trong danh mục không luôn là số vật phẩm sở hữu.

Snapshot v1

{
  "schema": "genshin-battle-chronicle-v1",
  "id": "snapshot UUID",
  "source": { "collectorVersion": "0.7.0", "clientDate": "2026-11-02" },
  "credentialSource": "hoyolab_web",
  "role": { "uid": "UID đã chọn", "server": "os_asia" },
  "state": "complete",
  "sections": { "overview": { "state": "ok", "data": {} } },
  "views": { "characters": [], "equippedWeapons": [], "equippedArtifacts": [] },
  "summary": { "characters": 0, "requests": 0 }
}

Ví dụ trên minh họa cấu trúc, không phải dữ liệu import. Snapshot còn có thời điểm bắt đầu/kết thúc và limitations. Mỗi section giữ endpoint/method, state, requestCount và dữ liệu API; module động giữ batches/pages/records thay vì mất phần đã đọc. stripCredentials loại key credential đệ quy và các key prototype nguy hiểm.

buildViews kết hợp list với detail. Mỗi bản vũ khí/thánh di vật có characterId; không gộp các bản cùng weapon ID. showcaseModel tạo profile, stats, characters, allProperties, propertyMap, regions, previewFacts, notes và module status gọn cho UI; không đưa toàn bộ body TCG vào view.

Phạm vi và trạng thái

Nhóm Dữ liệu
Hồ sơ & thế giới Role, overview, khu vực/nhóm khám phá, tượng, hiến tế, Ấm Trần Ca.
Nhân vật Toàn bộ list và detail theo batch; vũ khí, relics, stats, thiên phú, cung mệnh, field trang phục khi API trả.
Chiến đấu La Hoàn hiện tại/kỳ trước, các kỳ Nhà Hát/U Cảnh còn trả, popularity và Dư Âm.
Tiến độ Thành tựu, báo cáo sự kiện, lịch và daily notes.
Thất Thánh Tổng quan, danh mục thẻ phân trang, lưng thẻ, bộ bài/chi tiết, trận và các kỳ thử thách.
TPS Bỏ qua nếu mọi detail đã đọc đủ và unlock_tps=false; có cờ mở hoặc thiếu thông tin thì thử đọc.

Module state: queued, running, ok, not_applicable, partial, unavailable, error, skipped. Trạng thái lượt thu thập gồm idle, running, complete, partial, cancelled, expired, needs_verification, rate_limited, request_limit, failed.

Không đồng nhất dữ liệu thiếu với 0. Module khóa/ẩn/lỗi phải giữ lý do. Số thẻ danh mục khác số thẻ sở hữu. Chỉ các section ok/not_applicable mới cho kết quả complete. Snapshot gồm nhiều request, không phải một thời điểm máy chủ nguyên tử.

HTTP local

Chỉ chấp nhận Host 127.0.0.1:<port>. Không gửi query string. POST API cần cùng Origin, Content-Type: application/json, cookie phiên và header x-poc-csrf nhận từ GET session. Header/cookie có tên cũ để giữ tương thích; đừng đổi riêng một phía.

Method / route Kết quả hoặc đầu vào
GET /, /collector Giao diện chính; /collector là alias tương thích.
GET /README.html, /docs/ Tài liệu HTML.
GET /api/session {csrf, expiresAt, status}; tạo phiên nếu chưa có.
GET /api/showcase/saved {view}; bản đã lưu, không cần đăng nhập lại.
GET /api/showcase/archive JSON dữ liệu game đã lưu.
POST /api/login {account, password, profile: "hoyolab_web", deviceId}; UI mặc định web.
POST /api/captcha, /api/refresh-captcha Validation provider hoặc yêu cầu challenge mới, có giới hạn thủ công.
POST /api/send-otp, /api/otp Chỉ dùng khi flow đang có risk challenge hợp lệ.
POST /api/cookies, /api/roles, /api/select Cookie đã có / chọn route labRoles / {uid, server} thuộc role đã xác thực.
POST /api/collector/start Bắt đầu lượt; dùng giới hạn mặc định của collector.
POST /api/collector/status, /api/collector/view Trạng thái hoặc model UI hiện tại.
POST /api/collector/export, /api/collector/cancel Snapshot đã lọc hoặc dừng lượt và giữ dữ liệu đã đọc.
POST /api/reset Xóa credential, job và audit của phiên RAM; không xóa file dữ liệu game đã lưu.
GET /media/<base64url> Ảnh raster CDN công khai trong allowlist; không gửi cookie HoYoLAB.

Các route nghiên cứu cũ được giữ ở routes/api.mjs: Enka showcase, app/SDK exchange và wish backup. Không dùng chúng để thay flow web của collector. Mỗi kết quả API theo phiên kèm safeStatus; lỗi không xuất body hoặc header upstream.

Config preview

Key localStorage: genshin.preview.v2.<uid>.<server>. normalizeConfig whitelist công tắc, clamp số cột/hàng/item, loại ID không tồn tại và giới hạn 6 build. Mảng buildIds/statIds rỗng do người dùng chọn được giữ rỗng, không tự chọn lại.

planPreview tính trên chiều rộng cơ sở 1600 px, sau đó scale ra 1200/1600/2400/3200. Giới hạn hàng và item lấy mức chặt hơn; số tổng tài khoản giữ riêng. Stat lấy final từ các nhóm API, không tự tính buff chiến đấu. Khi đổi định dạng config, cần giữ tương thích hoặc tăng key version có chủ đích.
