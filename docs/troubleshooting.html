HANDBOOK / 05

Xử lý lỗiTìm nguyên nhân theo đúng lớp.

Bắt đầu bằng trạng thái hiện trên giao diện, rồi xem module và retcode. Không cần gửi password, OTP, cookie hay file data thật để mô tả lỗi.

Chạy local

Port 47932 đang bận

Chọn port mới, ví dụ PowerShell $env:HOYO_PORT = '47934', rồi chạy npm start và mở đúng 127.0.0.1:47934. Không dừng một dịch vụ khác khi chưa biết nó là gì. Dùng 127.0.0.1 thay vì localhost vì Host guard cố định.

npm ci / node không chạy

Kiểm tra node --version từ 22 trở lên và npm trong PATH. Chạy lệnh ở thư mục có package.json. Khi lockfile đổi, chạy npm ci lại. PowerShell chặn npm.ps1 thì có thể dùng npm.cmd với cùng tham số.

Frontend không đổi sau khi sửa

Frontend không có bundler/HMR; tải lại trang. npm run dev chỉ watch server; server restart sẽ xóa phiên RAM. Chạy npm run format và npm run check:source để tìm lỗi cú pháp, rồi kiểm tra console browser và request module có trả MIME JavaScript đúng không.

File data bị lỗi định dạng

App báo rõ và dừng thay vì ghi đè bằng rỗng. Backup file hiện tại trước; kiểm tra JSON/schema hoặc chọn HOYO_DATA_DIR mới rồi đồng bộ lại. Không đưa file lỗi thật lên Git để debug.

Đăng nhập và thu thập

Geetest loading lâu hoặc CAPTCHA không xuất hiện

Kiểm tra mạng có tải được domain Geetest/Captchami không, iframe sandbox và console có lỗi CSP hay script không. Dùng nút Yêu cầu CAPTCHA mới sau thời gian chờ; backend giữ đúng Device ID và bước đang chờ. Không liên tục nạp frame cũ và không dùng lại validation của challenge trước.

Vì sao đôi lúc vẫn có OTP?

Web login là mặc định và không ép gửi OTP. Nếu chính HoYoLAB trả risk challenge, app mới hiện xác minh bổ sung. Chỉ bấm gửi mã khi cần, nhập mã trên form local; không gửi vào chat. Không thể cam kết mọi lần đăng nhập web đều không OTP.

Expired / retcode -100

Phiên local hoặc credential upstream hết hạn. Tải lại và đăng nhập lại. Bản dữ liệu game đã lưu vẫn mở được nếu file tồn tại. Không dùng snapshot cũ như bằng chứng vừa đồng bộ thành công.

Rate limited / 429 / -3006

Collector dừng và tôn trọng Retry-After. Đợi trước khi thử lại; không tăng concurrency, đổi nhiều phiên hoặc bấm liên tục để vượt giới hạn. Giữ bản partial nếu cần xem các mục đã đọc.

Thiếu dữ liệu Nhà Hát / La Hoàn / vũ khí

Kiểm tra trạng thái từng module và quyền xem tài khoản. Chưa đánh hoặc chưa mở khóa có thể trả has_data=false/is_unlock=false. Vũ khí chỉ gồm trang bị trên các nhân vật, không phải toàn bộ túi đồ. Số thẻ danh mục không bằng số thẻ sở hữu.

Preview và PNG

Chọn giới hạn nhưng tổng số không giảm

Giới hạn áp dụng cho số ô đang hiện. Tiêu đề giữ cả tổng tài khoản, ví dụ 8 / 65; có thể tắt số lượng trong tiêu đề. 0 ở giới hạn là không giới hạn, không phải hiện 0 item.

PNG không tải được / ảnh quá lớn

Chọn ít nhất một phần nội dung và một nhân vật nếu bật build. Giảm số hàng, số build hoặc độ phân giải. Giới hạn trước khi vẽ là 32 megapixel và 16000 px chiều cao. Sau khi asset tải xong, nút Tải ảnh PNG mới được bật.

Thiếu icon hoặc ảnh bị lỗi

Kiểm tra request /assets hoặc /media, URL có thuộc allowlist và trả raster hợp lệ không. CDN game có thể đổi hoặc xóa asset; cập nhật game-assets.js và danh sách nguồn cùng nhau. Không thêm proxy tùy ý hoặc gửi cookie vào luồng ảnh để chữa lỗi CORS.

Muốn xóa tùy chỉnh cũ

Dùng Khôi phục mặc định trong preview. Config lưu riêng cho UID/server; đổi tài khoản không nên dùng lẫn ID nhân vật từ tài khoản trước. Khi đổi schema config cần normalize tương thích hoặc tăng key version có chủ đích.

Khi check hoặc CI thất bại

Check Cách xử lý
format:check Chạy npm run format, đọc diff rồi commit thay đổi định dạng.
check:source Sửa cú pháp ở module được báo; không cần tài khoản thật.
check:docs Sửa đường dẫn/anchor và mở lại trang HTML.
check:private Unstage file riêng, chuyển dữ liệu vào data; không nới .gitignore chỉ để check qua.
Test auth/collector Dùng fixture để kiểm tra thay đổi request/schema, giữ retcode và trạng thái lỗi.
