01 / KHỞI ĐỘNG

Clone, kiểm tra, rồi mở tài khoản.

git clone https://github.com/Ponie25/HoyoShowcase.git
cd HoyoShowcase
npm ci
npm start

Mở http://127.0.0.1:47932/. Bấm Đồng bộ dữ liệu, đăng nhập HoYoLAB Web trong form local, chọn UID nếu có nhiều role. Tự hoàn tất CAPTCHA nếu xuất hiện. OTP chỉ hiện khi HoYoLAB yêu cầu xác minh bổ sung; ứng dụng không tự gửi mã.

Lượt thu thập hoàn tất sẽ lưu dữ liệu game vào data/battle-chronicle-latest.json. Mở lại app sẽ đọc bản đã lưu trước; đồng bộ dữ liệu mới vẫn phụ thuộc máy chủ.

Mới clone sẽ chưa có tài khoản. Dữ liệu thật của người phát triển không nằm trong Git. Có thể dùng npm run demo để thử luồng bằng dữ liệu giả lập ở port 47933, không cần đăng nhập HoYoLAB.

Một bộ sưu tập, nhiều cách trình bày.

Danh sách và chi tiết nhân vật, trang bị đang gắn, thế giới, La Hoàn, Nhà Hát, U Cảnh, sự kiện, daily notes và Thất Thánh theo các mục API còn cung cấp.

Gallery & build

Lọc nguyên tố, tìm kiếm, sắp xếp, xem chi tiết trang bị. Giữ icon, tranh và nền độ hiếm từ game; nhấn mạnh 5★ C6.

Preview account

Chọn tổng số hiện, ô mỗi hàng, số hàng, lọc độ hiếm, hồ sơ và từng thông tin Chronicle. Thành tựu/ngày hoạt động mặc định tắt.

04

Một PNG hoàn chỉnh

Ghép tổng quan, khám phá và tối đa 6 build. Chọn từng chỉ số hoặc preset DPS/Hỗ trợ/Tinh thông; xuất 1200–3200 px.

Vũ khí và thánh di vật là các bản đang trang bị trên nhân vật; chưa có API kho túi đồ độc lập được xác nhận. App không khôi phục lịch sử mà API đã loại bỏ và không tự bật quyền công khai. Xem phạm vi và trạng thái dữ liệu.

03 / CÔNG CỤ PHÁT TRIỂN

Các lệnh dùng hàng ngày.

Lệnh Mục đích
npm start Chạy app thật, mặc định port 47932.
npm run dev Node watch; server khởi động lại khi source server đổi, phiên RAM sẽ mất. Frontend cần tải lại trang.
npm run demo Server với fixture giả lập, không gọi API tài khoản thật; mặc định port 47933.
npm test Kiểm thử bằng fixture, không cần cookie/password.
npm run format Chuẩn hóa JS, CSS, HTML, Markdown và YAML.
npm run check Định dạng, cú pháp, link tài liệu, tệp riêng tư và test.

04 / CẤU HÌNH

Port và chỗ lưu dữ liệu.

Biến môi trường Mặc định Ý nghĩa
HOYO_PORT 47932 / demo: 47933 Port loopback, từ 1024 đến 65535.
HOYO_DATA_DIR <repo>/data Thư mục lưu bản Chronicle; không dùng để lưu credential.
GENSHIN_COLLECTOR_PORT Không đặt Tên cũ, được hỗ trợ nếu HOYO_PORT chưa đặt; chỉ cho app thật.

Ví dụ PowerShell:

$env:HOYO_PORT = '47934'
$env:HOYO_DATA_DIR = 'C:/HoyoShowcase-data'
npm start

App không tự nạp tệp .env. Nếu chọn thư mục dữ liệu ngoài repo, tự quản lý backup tại đó. Không chạy hai app thật cùng ghi một thư mục dữ liệu. Server chỉ bind 127.0.0.1; đây chưa phải ứng dụng nhiều người dùng để đưa thẳng lên hosting.
